CE QUE CONTIENT LA V28 (suite de l'import ZIP Trakt)
----------------------------------------------------
1. TABLEAU DE BORD : les widgets (temps total, rythme, compteurs à
   vie, date de fin projetée) fonctionnent aussi avec un ZIP Trakt,
   sans connexion MDBList.
2. LIBELLÉS : « Watchlist Trakt (import ZIP) » au lieu de « Watchlist
   MDBList » quand les données viennent d'un ZIP.
3. EN COURS + FANTOME : les reprises en pause du ZIP apparaissent, et
   les séries en cours sont reconstruites depuis l'historique.
4. QUE REGARDER : bouton « ✨ Enrichir avec MDBList » sur le dashboard
   (genres, posters, durées, notes) — le filtre Genre, les posters et
   les scores différenciés apparaissent alors.
5. CALENDRIER : fonctionne en mode local sans connexion MDBList.
6. SAUVEGARDE : la restauration JSON est accessible sans connexion ni
   données chargées (recharge ton JSON directement).
7. HISTORIQUE DES AJOUTS : les dates listed_at du ZIP sont conservées.
8. LIENS : badges aussi sur « Que regarder ? », et « 🔎 Où regarder »
   en texte.

POUR TESTER (après import d'un ZIP Trakt)
------------------------------------------
1. Tableau de bord : tu vois maintenant les widgets rythme/temps
   même sans connexion MDBList.
2. « ▶️ En cours de lecture » : tes séries du ZIP apparaissent (nb
   épisodes vus + dernier visionnage).
3. « 👻 Progression Fantôme » : tes reprises en pause du ZIP.
4. Connecte MDBList puis clique « ✨ Enrichir avec MDBList » sur le
   dashboard : « 🎯 Que regarder ? » gagne le filtre Genre, les
   posters, les durées et les notes.
5. « 📤 Sauvegarde » : tu peux restaurer ton JSON même déconnecté.
