repo. Le plus simple : ÉDITION DIRECTE sur GitHub.
1. Ouvre : github.com/Minijoe01/Media-Smart-Lists/blob/main/
   .github/workflows/ci.yml
2. Clique le crayon ✏️ « Edit this file »
3. Remplace TOUT le contenu par celui du fichier ci.yml de
   cette livraison (ouvre-le dans le bloc-notes, copie tout)
4. « Commit changes » — le workflow se relance : il doit
   passer au vert au prochain commit ✅

Et pour test_core.py : va dans le dossier « tests » du repo →
Add file → Upload files → dépose test_core.py (remplace).

app.py : upload à la racine comme d'habitude.

Après ces 3 gestes + Reboot/Clear cache Streamlit, le prochain
commit GitHub affichera un CI vert (✔ 23 tests OK).
