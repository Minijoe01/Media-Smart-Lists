# Media Smart Lists — Étape 3

Cette étape restaure la coque visuelle de l'ancienne application :

- dégradé radial vert original ;
- palette Aston Martin ;
- boutons verre vert et bouton primaire en dégradé ;
- menu latéral complet ;
- toutes les anciennes entrées de navigation ;
- en-tête compact avec l'icône existante.

Les pages autres que le Dashboard sont volontairement des placeholders : leurs calculs seront reconnectés progressivement au modèle commun MDBList / ZIP Trakt.

## Installation

1. Dans GitHub : **Add file → Upload files**.
2. Envoyer `app.py` et `ETAPE-3.md`.
3. Vérifier que `app.py` est remplacé.
4. Commit : `ui: restore legacy theme and full sidebar navigation`.
5. Streamlit redéploiera automatiquement après le commit.
