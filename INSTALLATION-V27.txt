POUR TESTER L'IMPORT ZIP TRAKT
------------------------------
1. Sur https://trakt.tv → Settings → Your Data → Export, télécharge
   ton export ZIP.
2. Dans l'application : Tableau de bord → « 📦 Importer un ZIP Trakt ».
3. Dépose le ZIP → « 📥 Importer et charger mes données ».
4. Un récapitulatif s'affiche, puis toutes les pages utilisent tes
   données Trakt (Statistiques, Rendez-vous annuel, Succès,
   Calendrier, Sauvegarde).

IMPORTANT
---------
• Ne mettez JAMAIS .streamlit/secrets.toml sur GitHub (il est ignoré).
• L'import ZIP est en lecture seule : rien n'est modifié sur Trakt ni
  sur MDBList.
