COMMENT SUPPRIMER PLUSIEURS FICHIERS D'UN COUP SUR GITHUB
----------------------------------------------------------
L'interface web de GitHub ne permet de supprimer qu'UN fichier à la
fois (icône poubelle). Pour supprimer plusieurs fichiers en même
temps, utilisez GitHub Desktop (gratuit) :

1. Téléchargez GitHub Desktop : https://desktop.github.com
2. Ouvrez-le et connectez-vous avec votre compte GitHub.
3. File → Clone repository → choisissez votre dépôt
   (ex. Media-Smart-Lists) → Clone.
4. Dans la liste des fichiers, sélectionnez plusieurs fichiers
   (Ctrl+clic sous Windows / Cmd+clic sous Mac).
5. Clic droit → « Delete » (les fichiers passent en rouge).
6. En bas : écrivez un message de commit (ex. « Suppression fichiers
   obsolètes ») → « Commit to main ».
7. Cliquez sur « Push origin » (en haut) pour envoyer sur GitHub.

Répétez pour Trakt-Smart-Lists si besoin (après l'avoir récupéré —
voir ma réponse pour le revert).
